# India Health Connect

This project is a medical tourism application built with React, Vite, and Tailwind CSS.

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
